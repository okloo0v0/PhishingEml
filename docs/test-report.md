## 发现与处理

- 初次全量联调发现 1 封 malformed `Message-ID` 邮件触发解析器 500。
- 已修复为使用原始头字段读取，避免 Python header registry 对异常头直接抛出异常。
- 修复后该邮件重新测试成功：模型概率 0.9519，规则分 55.0，最终分 81.1，风险等级 `high`。

## 解释

- 训练测试集中的 `legitimate` 与 `phishing` 标签来自离线公开语料；本报告反映的是当前语料分布下的系统联调表现，不代表真实生产环境准确率。
- 规则分会叠加邮件结构特征，因此正常邮件也可能出现规则命中和中风险提示，需要结合证据人工复核。
