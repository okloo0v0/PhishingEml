# V1.2 Intent 分支收尾决策

## 决策

V1.2 生产主融合暂时固定为 `word + char + structure`，排除 `intent` 分支。原有
`models/intent_branch_v1_2.joblib` 保留为实验和解释模型，不删除代码、数据或评估产物。

本决定不是永久放弃 intent，而是避免在监督信号不足、类别稀疏和概率未充分校准时，让它影响
生产风险分数。后续只有在来源隔离人工数据上证明独立增益后，才重新进入 OOF 融合。

## 已完成工作

1. 建立七类行为意图本体：`credential_request`、`oauth_authorization`、`payment_change`、
   `external_document_action`、`reply_or_data_request`、`social_pressure`、`benign_notice`。
2. 实现关键词/否定词弱标注、字符 n-gram 多标签 Logistic Regression、语义护栏和逐类阈值。
3. 建立 46 条双语边界回归集，校准后精确匹配率从 91.3% 提升到 93.5%。
4. 对来源隔离 DiFraud 样本进行 100 条七类人工复核；该数据只用于测试，不参与生产模型训练。
5. 原 intent 模型在这 100 条人工集上的 exact-match 为 0.410、micro-F1 为 0.448。
6. 证实当前低频类别不足：`oauth_authorization` 1 条、`benign_notice` 3 条、
   `payment_change` 5 条。

## 四视图与三视图对照

使用相同既有训练数据和固定测试集重新训练三视图模型，未加入人工样本：

| 集合 | 四视图（含 intent） | 三视图（排除 intent） |
|---|---:|---:|
| 主测试集 F1 | 0.990 | 0.990 |
| 来源留出 F1 | 0.989 | 0.989 |
| 中文测试 F1 | 1.000 | 0.000 |
| 现代攻击测试 F1 | 0.857 | 0.679 |
| 边界测试 F1 | 0.903 | 0.533 |

解释：主测试集和来源留出集没有实质差异，说明 intent 没有稳定的普适增益；中文和边界集的
下降表明它仍捕获了部分局部模式，但这些测试集是人工构造/规模较小，不能单独支持生产融合。
因此 V1.2 选择可控的三视图主模型，同时保留 intent 作为研究分支。

## 后续重新启用条件

- 每个 intent 至少 100 条人工标注，低频类别优先补齐；
- 训练、校准、来源留出测试严格分离；
- 增加词面相近但意图相反的对照样本；
- 将关键词命中升级为动作-对象-主体-否定关系特征，必要时采用冻结式多语言句向量；
- 在 OOF 消融中相对三视图基线稳定提升，并通过来源留出和硬负样本测试；
- 在满足上述条件前，不调整现有生产融合权重。
